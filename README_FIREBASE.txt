IMPORTANTE - Firebase

Antes de publicar esta versão:
1. Firebase Console > Build > Firestore Database
2. Create database
3. Start in test mode

Depois:
1. Substitui os ficheiros no GitHub
2. Commit changes
3. Abre admin.html
4. Login
5. Carrega em "Enviar Dados para Firebase"

A partir daí:
- Admin altera resultados
- Público vê em tempo real noutros telemóveis/PCs
